# Совместимость Folio 1.14.0

Состояние реализации: 22 октября 2026 года. APK предназначен для Android 8.0 / API 26 и новее. Поддержка конкретной модели подтверждается на устройстве; название производителя не заменяет проверку датчиков и прошивки.

| Платформа или функция | Что реализовано | Что ещё требуется |
| --- | --- | --- |
| Samsung, Honor, Lenovo, OPPO, vivo, OnePlus, Google и другие планшеты Android | Стандартные TOOL_TYPE_STYLUS / TOOL_TYPE_ERASER; текущие и исторические отсчёты нажима; наклон и направление; hover; кнопки через MotionEvent и новые KeyEvent | Физические проверки каждой модели и доступности её аппаратных сигналов |
| Huawei с Android-совместимой прошивкой | Тот же стандартный ввод, если прошивка передаёт MotionEvent | Проверка конкретной прошивки; отдельные жесты M-Pencil не подключены |
| Xiaomi / Redmi / POCO и Focus Pen Pro | Сохранены общий помощник с FocusFlow, расширенные жесты и канал вращения Xiaomi | Проверка новой версии после установки; другие перья Xiaomi не объявлены эквивалентом Focus Pen Pro |
| Samsung Air Actions | Обычные переданные Android кнопки обрабатываются | Удалённые BLE-жесты Air Actions требуют отдельной интеграции; в этой сборке её нет |
| iPad / Apple Pencil | Эта APK на iPadOS не устанавливается | Отдельное приложение iPadOS с UIKit / Pencil API; текущая сборка не является портом для iPad |
| HarmonyOS без совместимости с Android APK | Не реализовано | Отдельный порт на соответствующий SDK |

## Изменения обработки ввода

- Нажим приводится к 0…1 по InputDevice.MotionRange, включая нестандартный максимум и ненулевой минимум. Один диапазон используется для новых и исторических отсчётов. При отсутствии метаданных сохраняется корректный стандартный отсчёт; отсутствие нажима получает безопасный резерв.
- Некорректные и нечисловые значения наклона, направления и нажима не попадают в геометрию штриха.
- Одна кнопка, одновременно сообщённая через KeyEvent и MotionEvent, не выполняет действие дважды. Удержание кнопки не повторяет команду; быстрые отдельные нажатия одного канала сохраняются.
- Если ладонь коснулась экрана первой, последующий указатель стилуса может забрать поток по своему pointer ID. Пальцы не превращаются в перо; отменённый контакт не сохраняется.
- Обратная сторона пера TOOL_TYPE_ERASER временно выбирает ластик. По завершении контакта восстанавливаются исходный инструмент и его параметры. В настройках сохраняется выбранный инструмент, а не временная обратная сторона.
- Скан-коды Focus Pen отделены от обычной клавиатуры. Расширение Xiaomi и карточка ADB не включаются на обычном Android-устройстве другого производителя без обнаруженного Focus Pen. Стандартному рисованию этот помощник не нужен.
- Поворот направления AXIS_ORIENTATION не объявляется датчиком вращения корпуса. Канал настоящего вращения Focus Pen Pro остаётся отдельным расширением Xiaomi.

## Проверки и пределы результата

51 проверка выполняет настоящий код обработки диапазонов, кнопок и выбора расширения с подменённым транспортом Android на JVM. Это проверка программной логики, а не сертификация планшетов перечисленных производителей.

`tests/CompatibilityEraserTests.java` — отдельная нативная проверка Android: объединение перерисовок ластика, наложение маркера, защищённые слои, undo/redo/cancel, ладонь перед пером и обратный ластик. Она использует временный холст и не изменяет пользовательские тетради. Пакет с тестом собран, но не запускался: ADB-устройство не подключено. В обычной APK тестовых компонентов нет.

Физические сжатия, свайпы корпуса, мотор отклика, настоящая задержка экрана и возможности отдельной прошивки не подтверждены настольными тестами. В эту версию не включались закрытые SDK Huawei, Honor, OPPO или vivo.

## Первичные источники

- [Android: advanced stylus features](https://developer.android.com/develop/ui/views/touch-and-input/stylus-input/advanced-stylus-features) — типы указателей, оси, исторические отсчёты и отклонение ладони.
- [Android: InputDevice.MotionRange](https://developer.android.com/reference/android/view/InputDevice.MotionRange) — диапазоны осей устройства.
- [Android: KeyEvent](https://developer.android.com/reference/android/view/KeyEvent) — стандартные кнопки стилуса; новые коды добавлены в API 34, старые устройства могут сообщать кнопки через MotionEvent.
- [Samsung: Air Actions](https://developer.samsung.com/galaxy-spen-remote/air-actions.html), [S Pen Remote SDK](https://developer.samsung.com/galaxy-spen-remote/s-pen-remote-sdk.html) — отдельные интерфейсы удалённых BLE-жестов и ограничения доступности.
- [Apple: Pencil interactions](https://developer.apple.com/documentation/uikit/apple-pencil-interactions), [UITouch.rollAngle](https://developer.apple.com/documentation/uikit/uitouch/rollangle) — API отдельной платформы iPadOS.
