# Folio Canvas · плагин 0.3.0

Доступ к открытому холсту Folio из разных сетей через HTTPS. VPN остаётся включённым.
Нужен Folio 1.18.0-preview.1. Общая Wi-Fi сеть, проброс портов и ADB не нужны.

## Подключение планшета

1. Установите APK обновлением поверх Folio, сохранив его данные.
2. Откройте https://folio-canvas-link.mikhailllm.chatgpt.site в браузере планшета.
3. Войдите в свой аккаунт ChatGPT, создайте подключение и скопируйте его.
4. В Folio откройте настройки → Folio × ChatGPT / Codex → Вставить облачное подключение.
5. Включите доступ. Держите тетрадь открытой, пока помощник работает с холстом.

Секретную строку не отправляйте в чат и другим людям. Отозвать её можно на странице
подключения; после этого потребуется повторное сопряжение планшета и локального плагина.

## ChatGPT и облачный Codex

Используйте приватный плагин Folio, созданный вместе с облачным сервисом Sites.
Вход выполняется через ваш аккаунт ChatGPT. Отдельный сервер на ПК или туннель
для этого режима не требуется. Плагин нужно подключить к чату.

## Локальный Codex на ПК

1. Распакуйте Folio-Canvas-Plugin-0.3.0.zip.
2. Запустите Install-Codex-Plugin.cmd (Python 3.11+ и Codex CLI).
3. Запустите folio-plugin/Setup-Folio-Plugin.cmd и вставьте ту же строку подключения.
4. Откройте новый чат Codex и включите Folio Canvas.

Настройки хранятся в %USERPROFILE%/.folio-plugin, ключ вводится скрыто.
Используются системные HTTPS-прокси Windows и переменные прокси окружения.
Для установки из исходников:

```powershell
python integrations/folio-plugin/setup.py
codex plugin marketplace add .
codex plugin add folio-canvas@folio-local
```

Старый LAN-режим сохранён для совместимости, облачный режим работает через
исходящие HTTPS-запросы устройств. Сервер может расшифровать данные для исполнения
MCP-команд; это не сквозное шифрование от сервера. Очередь зашифрована AES-GCM,
запросы ограничены по времени и аккаунту. Никакой ключ OpenAI API не нужен.

## Команды

- «Прочитай открытый холст Folio».
- «Напиши “Привет!” синим в свободном месте».
- «Нарисуй схему справа от моего конспекта».
- «Убери последнюю запись, которую ты добавил».

Сначала плагин читает холст, его идентификаторы и версию. При изменении страницы
запись отклоняется, чтобы не попасть в другую тетрадь. Повтор одной операции не
добавляет копию штрихов. Отмена плагина удаляет только указанную ИИ-запись; обычная
история Folio тоже работает. Ответ `autosave: queued` означает постановку в штатную
очередь сохранения Folio, не подтверждение завершённой записи на диск.

## Почерк

`neat` — встроенный печатный рукописный стиль с русскими и латинскими буквами,
цифрами и базовыми математическими знаками. Это одноштриховые векторные буквы,
а не текстовый блок или картинка. Сложные формулы и схемы можно строить отдельными
штрихами через `folio_draw_ink`.

`personal` — ваш профиль из реальных векторных образцов. Напишите букву или слово
в Folio, выделите его лассо и попросите: «Запомни выделенное как букву А моего
почерка». Нужные для будущего текста символы следует записать отдельно. Целые
слова сохраняют ваши соединения. Если образца нет, инструмент сообщает об этом;
он не подменяет ваш почерк другим стилем. Это композиция образцов, не обучение
нейросети и не воспроизведение произвольных связок букв. В локальном плагине профиль хранится на ПК, в облачном — в вашем закрытом аккаунте Folio Cloud.

## Проверка релиза

Проверены сборка и подпись APK, реальный MCP stdio обмен через официальный SDK,
передача PNG/штрихов, конфликт версии страницы, отмена ИИ-записи с сохранением
пользовательских штрихов, сохранение/применение образцов и отказ при их отсутствии.
HTTP-сервер Folio проверен на JVM с заменённым Android UI: ключ, запрет browser
Origin, фоновое состояние, версии, повтор запросов, атомарная проверка пакета.
Физическая проверка этого нового сетевого интерфейса и диалога на планшете ещё
не выполнена: планшет недоступен. Это предварительная версия.

## Почерк из существующих тетрадей

Попросите плагин проанализировать выбранные тетради: он перечислит страницы,
прочитает изображения рукописных штрихов и сохранит уверенно распознанные буквы
и слова. На больших бесконечных страницах он может просмотреть несколько областей.
Неясные слова требуют проверки. Скрытые и частично стёртые штрихи и записи ИИ
не добавляются в профиль. Это набор векторных образцов, а не обученная нейросеть:
для неизвестных букв нужны дополнительные примеры.

На странице Folio Cloud можно экспортировать профиль в защищённый паролем файл
и импортировать в другой аккаунт или на свой сервер. Экспорт не содержит ключа
подключения планшета. Облачный и локальный профили хранятся отдельно.
