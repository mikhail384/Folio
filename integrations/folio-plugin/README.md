# Folio Canvas · плагин 0.1.0

Пишет непосредственно на открытом холсте Folio: редактируемые штрихи, рисунки,
просмотр страницы и отмена отдельной ИИ-записи. Нужен Folio 1.16.0-preview.1 или новее.
API OpenAI и отдельный ключ модели не требуются для локального MCP-подключения Codex.
Плагин не содержит готового доступа к вашему планшету или пользовательским заметкам.

## Подключение планшета

1. Установите APK обновлением, без удаления Folio и его данных.
2. Откройте тетрадь. В настройках Folio выберите **Folio × ChatGPT / Codex**.
3. Включите подключение и нажмите **Скопировать подключение**.
4. ПК и планшет должны быть в одной доверенной локальной сети Wi-Fi. VPN и изоляция
   клиентов роутера могут мешать связи. Проброс портов в интернет не нужен.
5. На ПК нужен Python 3.11+ (на машине разработки проверен Python 3.14).
   Запустите `Setup-Folio-Plugin.cmd` и вставьте скопированный JSON подключения.
   Ввод ключа скрыт; настройки остаются в `%USERPROFILE%\.folio-plugin`.

Folio принимает команды только пока приложение открыто. При уходе в фон сервер
закрывается. Доступ ограничен открытой тетрадью; ключ можно отключить или сменить
в приложении. Если IP планшета поменялся, повторите копирование и настройку.
Подключение HTTP предназначено для доверенной локальной сети, не для публичного
доступа. MCP-сервер для туннеля слушает только `127.0.0.1`.

## Codex

В скачанном полном пакете запустите `Install-Codex-Plugin.cmd` из верхней папки.
Он подготовит отдельное окружение Python и добавит локальный плагин. Затем
перезапустите Codex или откройте новый чат, подключите **Folio Canvas**.

Для установки из репозитория:

```powershell
python integrations/folio-plugin/setup.py --deps-only
codex plugin marketplace add .
codex plugin add folio-canvas@folio-local
```

Для клиента MCP без каталога плагинов можно использовать stdio:

```json
{"mcpServers":{"folio":{"command":"python","args":["C:/полный/путь/folio-plugin/launch.py"]}}}
```

## ChatGPT

Пакет содержит настоящий MCP-сервер. Запустите `Start-ChatGPT-MCP.cmd`, получите
локальный Streamable HTTP endpoint `http://127.0.0.1:18766/mcp`.
Облачный ChatGPT не подключается непосредственно к этому localhost. Его нужно
соединить через **Secure MCP Tunnel** с узлом, где работает сервер, затем добавить
личный MCP-плагин в поддерживаемом интерфейсе ChatGPT. Нужны доступ к созданию
пользовательских MCP-плагинов, туннель и его собственные учётные данные. Они в
пакет не включены. Публичного облачного сервера Folio этот релиз не разворачивает.

Официальные инструкции:
- https://developers.openai.com/api/docs/guides/secure-mcp-tunnels
- https://developers.openai.com/plugins/quickstart

## Команды

- «Прочитай открытый холст Folio».
- «Напиши “Привет!” синим в свободном месте».
- «Нарисуй схему справа от моего конспекта».
- «Убери последнюю запись, которую ты добавил».

Сначала плагин читает холст, его идентификаторы и версию. При изменении страницы
запись отклоняется, чтобы не попасть в другую тетрадь. Повтор одной операции не
добавляет копию штрихов. Отмена плагина удаляет только указанную ИИ-запись; обычная
история Folio тоже работает. Ответ `autosave: queued` означает постановку в штатную
очередь сохранения Folio, не подтверждение завершённой записи на диск.

## Почерк

`neat` — встроенный печатный рукописный стиль с русскими и латинскими буквами,
цифрами и базовыми математическими знаками. Это одноштриховые векторные буквы,
а не текстовый блок или картинка. Сложные формулы и схемы можно строить отдельными
штрихами через `folio_draw_ink`.

`personal` — ваш профиль из реальных векторных образцов. Напишите букву или слово
в Folio, выделите его лассо и попросите: «Запомни выделенное как букву А моего
почерка». Нужные для будущего текста символы следует записать отдельно. Целые
слова сохраняют ваши соединения. Если образца нет, инструмент сообщает об этом;
он не подменяет ваш почерк другим стилем. Это композиция образцов, не обучение
нейросети и не воспроизведение произвольных связок букв. Профиль хранится локально.

## Проверка релиза

Проверены сборка и подпись APK, реальный MCP stdio обмен через официальный SDK,
передача PNG/штрихов, конфликт версии страницы, отмена ИИ-записи с сохранением
пользовательских штрихов, сохранение/применение образцов и отказ при их отсутствии.
HTTP-сервер Folio проверен на JVM с заменённым Android UI: ключ, запрет browser
Origin, фоновое состояние, версии, повтор запросов, атомарная проверка пакета.
Физическая проверка этого нового сетевого интерфейса и диалога на планшете ещё
не выполнена: планшет недоступен. Это предварительная версия.
