Запуск без компьютера

Встроенный помощник

Первое сопряжение выполняется по коду Android.

1. Разрешите локальное подключение

Подключите планшет к Wi-Fi. В настройках разработчика включите «Беспроводная отладка» и выберите «Сопряжение с помощью кода».

Откройте настройки рядом с FocusFlow в разделённом экране. Окно с кодом должно оставаться открытым во время сопряжения.

2. Введите код сопряжения

Порт находится после двоеточия в строке «IP-адрес и порт». Код не сохраняется.

3. Автоматическое подключение

После сопряжения закройте окно кода. При открытии Folio или FocusFlow помощник подключается автоматически. Порт определяется сам; при необходимости его можно указать вручную.

Один помощник обслуживает Folio и FocusFlow. Пока открыт Folio, команды FocusFlow приостановлены. После перезагрузки откройте Folio или FocusFlow. Если отладка выключена, появится уведомление с кнопкой настроек. После её включения запуск продолжится автоматически. Повторное сопряжение обычно не требуется.

Служба управления

Для выполнения ваших действий должна быть включена служба FocusFlow в специальных возможностях Android.

Подключение выполняется только к этому планшету (127.0.0.1). Все библиотеки и помощник включены в APK. Root, компьютер и установка других приложений не требуются.
