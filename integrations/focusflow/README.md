# FocusFlow 1.7.1 — интеграция с Folio

Исходники совместимого обновления исходного FocusFlow 1.5. Присланный APK и исходный локальный выпуск совпали побайтно; SHA-256, версия и сертификат находятся в provenance.json.

Из корня проекта Folio: `python scripts/build_focusflow.py`. Пять исходных библиотек в libs/ проверяются по dependencies.lock.json. Нужен JDK 17 / Android SDK 35 и исходный ключ FocusFlow через FOCUSFLOW_KEYSTORE либо прежний portable-каталог. Ключ не входит в исходники и никогда не заменяется автоматически новым.

Функции, UI и SharedPreferences FocusFlow сохранены. Общий ADB-помощник вынесен в ../../shared/penbridge. Запуск без ПК использует прежнее сопряжение ADB и запускает помощник для обоих приложений. Когда Folio на переднем плане, ожидающие и новые команды FocusFlow отменяются; после выхода новые жесты снова доступны. Кнопка остановки приостанавливает только команды FocusFlow.

Тесты интеграции из корня: `python scripts/test_shared_pen.py`, `python scripts/test_shared_host.py`. Они работают на JVM/имитации ADB и не заменяют проверку на планшете. Установленная проверка подготовлена: `python scripts/verify_shared_pen.py` — переходы Folio/Home/FocusFlow, диагностика маршрута, один процесс; назначения и документы не меняются.

Пользовательский сценарий установки и ограничения описаны в корневом README.md. Частные ключи и данные приложений в пакет не включаются. При открытии Folio или FocusFlow связанная служба AutoAdbService проверяет heartbeat и запускает помощник через сохранённое сопряжение. Отключённая беспроводная отладка показывает карточку настроек. Это запуск при открытии приложения, без boot receiver. Подробности и отчёт JVM-проверок: корневой README.md, scripts/test_auto_adb.py и dist/auto-adb-tests.txt.

В 1.7.1 исправлено распознавание старого standalone-помощника: heartbeat без sharedProtocol больше не считается общим подключением Folio. Read-only статус Folio проверяется отдельно; добавлен перезапуск общего помощника при потерянной связи. Регрессии: scripts/test_auto_adb.py и scripts/test_provider_health.py.
