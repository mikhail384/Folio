# Folio Canvas Link на своём сервере

Это самостоятельный сервер Folio: веб-страница, защищённое подключение планшета,
MCP с OAuth и экспорт/импорт профилей почерка. Он не переносит данные из другого
аккаунта автоматически. Профили можно перенести через зашифрованный файл на сайте.

Нужен Node.js 24 или новее. Приложение слушает только `127.0.0.1` на порту из
`FOLIO_PORT` и ожидает публичный HTTPS reverse proxy. Укажите публичный URL в
`FOLIO_ORIGIN` и закрытый каталог данных в `FOLIO_DATA_DIR`; при первом запуске
потребуется одноразовый `FOLIO_SETUP_TOKEN` длиной не менее 32 символов.
Сохраните пароль Folio, который вы зададите на странице первоначальной настройки.

`deploy/test-109/` содержит конфигурацию тестового экземпляра на
`https://109.66.236.217:17443`: отдельный пользователь, systemd-сервисы,
локальный backend на 18080 и отдельный HTTPS-посредник. Это пример для данного
сервера, не универсальный установщик. Не запускайте его на другом узле без
проверки портов, путей и существующих служб.

Сертификат Let's Encrypt для IP недолговечен. Таймер проверяет продление дважды
в день; проверка использует временное прослушивание TCP-порта 80. При занятом
порту или отключённом таймере продление может не пройти. Скрипт развёртывания
сертификата обновляет только HTTPS-сервис этого тестового Folio.

Локальная проверка: `node --test tests/server.test.mjs`. Для полной проверки
нужны настоящий HTTPS, учётная запись и подключённый планшет.
