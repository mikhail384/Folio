# Folio: основной сервер и резерв

Публичный вход: `https://109.66.236.217:17443`. Шлюз на резервном VPS использует
зашифрованный SSH-туннель к отдельному экземпляру Folio на `31.77.128.190`.
Этот экземпляр хранит свои данные в `/var/lib/folio-mirror/state`; прежний Folio
на основном сервере и VPN-службы не изменяются.

Шлюз подтверждает изменяющий запрос только после создания и проверки копии
SQLite и объектов на резервном VPS. Копия содержит ключи и данные пользователя,
поэтому хранится в закрытом каталоге `/var/lib/folio-failover`. Во время создания
копии обработка запросов на основном экземпляре ненадолго приостанавливается.
Если связь оборвалась во время запроса, результат может быть неизвестен: перед
повторной записью нужно прочитать холст. Шлюз не повторяет такой запрос сам.

После трёх неудачных проверок основной службы шлюз поднимает локальный экземпляр
из последней проверенной копии. После включения резерв остаётся основным и после
возвращения первого VPS или перезапуска шлюза. Автоматического возврата нет:
перед переносом обратно нужно остановить запись, сохранить состояние обоих узлов
и отдельно перенести более новые данные с резерва на основной сервер. Иначе можно
потерять изменения, сделанные после переключения.

Сам входной VPS является общей точкой доступа: если он недоступен, этот адрес
не сможет автоматически открыться на другом сервере. Для независимого адреса
нужен управляемый домен и отдельный сервис переключения или другой внешний вход.
Сертификат IP обновляется таймером `folio-canvas-test-renew.timer`; его deploy
hook перезапускает `folio-gateway.service`. На обоих узлах требуется сетевой
доступ по SSH между ними и работающее доверенное системное время.

Сервисные имена: `folio-primary-gateway` на основном VPS, `folio-gateway-tunnel`
и `folio-gateway` на резервном. Новый вход использует копию состояния прежнего
Folio на момент переноса: дальнейшие изменения в старом адресе не синхронизируются.
Планшет и ChatGPT нужно один раз подключить к новому входу. Старые настройки
на планшете не меняются до ручного импорта нового подключения.
