# Калькулятор дробей (Android)

Kotlin + Jetpack Compose. Складывает, вычитает, умножает и делит обыкновенные и смешанные дроби;
результат показывается как несократимая дробь, смешанное число и десятичная запись.
Пустые поля: целая часть и числитель = 0, знаменатель = 1. Для отрицательного смешанного числа знак ставится у целой части.

Открыть папку `android/` в Android Studio (Hedgehog+) и запустить, либо `gradle :app:assembleDebug`
(нужны JDK 17 и Android SDK 34). Тесты логики: `gradle :app:testDebugUnitTest`.
