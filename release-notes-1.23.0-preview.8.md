# Folio 1.23.0-preview.8

Исправлена обработка успешного OAuth callback: OpenAI обычно не передаёт параметр `error`, поэтому отсутствующие query-параметры теперь нормализуются в пустую строку до проверки. Та же защита применяется к `state`, `code`, `client_id` и `scope`.

Сборку и вход на планшете нужно проверить после установки. Предыдущая версия могла завершать разбор callback исключением `String.isEmpty()` на null.
