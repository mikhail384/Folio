# Folio 1.23.0-preview.6

Предварительная сборка с прямым доступом к ChatGPT из Folio без API-ключа.

- Добавлен Sign in with ChatGPT через OAuth Authorization Code + PKCE.
- Сообщения идут в публичный Responses API; ответы постепенно отображаются в окне Folio.
- Можно прикрепить снимок текущего вида холста и выбрать вывод ответа в окне или на странице.
- OAuth-токены хранятся зашифрованными ключом Android Keystore и обновляются автоматически.
- Удалён старый сценарий, открывавший отдельное приложение ChatGPT.

Требуется подтверждение входа в браузере и разрешение ChatGPT plan usage для аккаунта и интеграции. Проверена сборка исходников; подключение к реальному аккаунту и проверка на планшете пока не выполнены.
