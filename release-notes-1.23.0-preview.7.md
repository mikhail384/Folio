# Folio 1.23.0-preview.7

Предварительная сборка с возвратом в Folio после входа в ChatGPT и генерацией рукописных ответов.

- Во время OAuth-входа Android удерживает локальный callback активным в foreground-службе; ожидание увеличено до 15 минут.
- После callback браузер пытается автоматически открыть Folio; на странице возврата также есть кнопка.
- Добавлен режим «Мой почерк»: он создаёт новые сглаженные векторные штрихи из размеченных образцов букв, соединяет подходящие пары букв и оставляет формулы раздельными.
- В калибровку добавлены знаки пунктуации и формул. Если нужных символов нет в профиле, ответ остаётся в окне ChatGPT, без подмены стандартным шрифтом.

Сборка компилируется и подписана локальным сертификатом Folio. Возврат из браузера и визуальное сходство почерка ещё нужно подтвердить на планшете; сейчас устройство недоступно для проверки.
