# Калькулятор дробей (Android)

Приложение для действий с обыкновенными дробями: сложение, вычитание, умножение и деление.

## Возможности

- Дроби со знаком, включая смешанные числа (целая часть + дробь).
- Результат выводится тремя способами: несократимая дробь, смешанное число и десятичная запись.
- Десятичная запись точная для конечных дробей (до 10 знаков после запятой); остальные значения округляются до 6 знаков и помечаются знаком «≈».
- Проверки ввода: знаменатель не может быть нулём, на ноль делить нельзя.
- Светлая и тёмная темы; на Android 12+ цвета берутся из обоев (Material You).

## Стек

- Kotlin 2.0, Jetpack Compose с Material 3, ViewModel.
- Минимальная версия Android: 8.0 (API 26). Целевая: API 35.
- Для сборки нужен JDK 17 или новее (его включает Android Studio).

## Сборка и запуск

Откройте папку `fraction-calculator` в Android Studio и нажмите Run.

Из командной строки:

```sh
./gradlew :app:testDebugUnitTest   # юнит-тесты логики
./gradlew :app:assembleDebug       # APK: app/build/outputs/apk/debug/app-debug.apk
```

## Структура

```
app/src/main/java/com/example/fractions/
├── MainActivity.kt        точка входа
├── core/                  чистая логика без Android: дроби, разбор ввода, форматирование
│   ├── Fraction.kt        класс дроби с нормализацией (НОД) и арифметикой
│   ├── FractionFormat.kt  вывод: «7/6», «1 1/6», «≈1,166667»
│   └── Calculation.kt     разбор полей ввода, операции, ошибки
└── ui/                    экран (Compose), ViewModel, тема
app/src/test/              юнит-тесты core (JUnit 4)
```

Логика отделена от интерфейса, поэтому её можно проверять тестами без эмулятора.

## Перед публикацией

- Замените `applicationId` и `namespace` в `app/build.gradle.kts` (сейчас `com.example.fractions`).
- Настройте подпись релизной сборки; сейчас `release` собирается без минификации и без подписи.
