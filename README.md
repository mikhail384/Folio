# Folio

Android-приложение для заметок и рисования со стилусом. Текущая версия: Folio 1.13.3; общий помощник жестов — FocusFlow 1.7.1.

## Установка

Откройте раздел Releases и загрузите Folio.apk. Для общего помощника пера установите также FocusFlow.apk, если версии 1.7.1 ещё нет. APK устанавливаются поверх существующих приложений, без удаления и очистки данных.

Folio-FocusFlow.zip содержит оба APK, USB-установщик, скрипты запуска и отчёты проверки. SHA256SUMS.txt содержит контрольные суммы файлов.

## Что изменилось в 1.13.3

Название проверяется по существующим файлам: свободное имя сохраняется без индекса, при совпадении выбирается первый свободный (1), (2) и далее. Для пустого поля используется текущая дата. Учтены переименование, импорт и очередь незавершённых сохранений.

## Жесты пера

Для Xiaomi Pad 7 и Focus Pen Pro расширенные жесты используют общий ADB-помощник с FocusFlow. Первичное сопряжение беспроводной отладки выполняется в FocusFlow; затем при открытии приложений помощник запускается через сохранённое сопряжение. В открытом Folio команды FocusFlow приостановлены. Для действий FocusFlow вне Folio нужна его служба специальных возможностей.
