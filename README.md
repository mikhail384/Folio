# Folio

Android-приложение для заметок и рисования со стилусом. Текущая версия: **Folio 1.14.0**; расширенные жесты Focus Pen Pro используют **FocusFlow 1.7.1**.

[Скачать последнюю версию](https://github.com/mikhail384/Folio/releases/latest) · [Совместимость](COMPATIBILITY.md) · [Измерения ластика](PERFORMANCE.md)

## Установка

В Releases выберите Folio.apk и установите поверх существующей версии без удаления и очистки данных. Для расширенных жестов Xiaomi Focus Pen Pro установите также FocusFlow.apk, если версии 1.7.1 ещё нет. Folio-FocusFlow.zip содержит оба APK, USB-установщик, скрипты запуска и отчёты проверки. SHA256SUMS.txt — контрольные суммы.

## Новое в 1.14.0

Ластик использует кэш точной геометрии плоского маркера и объединяет растровые обновления к следующему кадру. Промежуточные сегменты не теряются; порядок и прозрачность наложенных полос, защищённые слои, отмена и повтор сохраняются. Обновляется окантовка области стирания без расширения векторного радиуса ластика.

Стандартный ввод Android нормализует нажим по устройству, обрабатывает исторические отсчёты, наклон, направление и кнопки. Одно нажатие не исполняется дважды при дублирующихся сигналах драйвера. Исправлены ладонь перед пером и возврат инструмента после обратного ластика. Службы Xiaomi отделены от общего ввода.

## Проверка и совместимость

Настольные проверки геометрии, сохранения и ввода пройдены; подписи APK проверены. Нативный Android-тест собран, но пока не запускался. Физическая задержка, возможности отдельных планшетов и новые APK на устройстве ещё не проверены. Для iPad создан отдельный нативный проект; APK остаётся Android-приложением. Матрица реализации и ограничения находятся в COMPATIBILITY.md.
