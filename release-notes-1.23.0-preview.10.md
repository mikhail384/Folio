# Folio 1.23.0-preview.10

- Исправлено добавление другого ChatGPT-аккаунта: для каждой новой регистрации используется `dynamic_agent_client`, а не `client_id` активного аккаунта.
- Аккаунты и OAuth-регистрации хранятся отдельно в зашифрованном виде. Добавление второго аккаунта больше не перезаписывает первый.
- Кнопка «Аккаунты ChatGPT» открывает список сохранённых учётных записей и пункт добавления новой.
- При смене активной учётной записи не смешиваются refresh token, разрешения или client ID разных аккаунтов.

Основано на актуальных инструкциях OpenAI по управлению несколькими регистрациями Sign in with ChatGPT. Авторизацию второго аккаунта нужно подтвердить на планшете.
