# Folio 1.23.0-preview.5

Предварительная сборка с быстрым доступом к ChatGPT из открытой тетради.

- Кнопка ChatGPT добавлена на плавающую панель холста; тот же переход доступен в настройках «Folio × ChatGPT / Codex».
- В Folio можно составить вопрос и открыть его в официальном приложении ChatGPT. Перед отправкой текст можно проверить и изменить.
- По отдельному выбору можно приложить снимок текущей страницы. Без приложения ChatGPT Folio копирует текст и открывает chatgpt.com.
- Для передачи используется системная отправка Android; отдельный API-ключ не требуется. Ответ остаётся в ChatGPT.

Передача текста и изображения проверена сборкой APK. Проверка открытия ChatGPT на планшете для этой версии ещё не выполнена.
